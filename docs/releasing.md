# Archived legacy releases

This repository is archived and read-only. Its final Go module and GitHub
archive release is `v1.10.1`, pinned to canonical `v1.10.1`. Synchronization
automation and release helpers have been retired; no further legacy Go tags
or GitHub releases will be published here.

Existing Git history, module/install paths, tags and archive URLs remain
available. Historical tags and assets are immutable. For future Go updates,
use `github.com/baldaworks/codex-acp` and its canonical command/import paths.

The deprecated npm alias `@normahq/codex-acp-bridge` continues to be published
from the canonical repository using shared `@baldaworks/codex-acp-*` native
packages. It does not depend on this repository remaining writable.

All ongoing development and publication belong to
[baldaworks/codex-acp](https://github.com/baldaworks/codex-acp).
See [canonical releasing](https://github.com/baldaworks/codex-acp/blob/main/docs/releasing.md)
and [migration policy](https://github.com/baldaworks/codex-acp/blob/main/docs/migration.md).
